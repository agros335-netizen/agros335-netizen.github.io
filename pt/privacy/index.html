Privacidade

O formulário de orçamento recolhe os seus contactos e os detalhes da viagem para que a Autolinee Sequi Srl, Via Pacinotti 28/30, Santa Croce sull’Arno (PI), possa responder ao pedido. Os campos assinalados são necessários para o tratamento do pedido. Os dados são transmitidos ao FormSubmit, que os encaminha para info@sequi.it e declara conservar uma cópia durante 30 dias. Detalhes: https://formsubmit.co/privacy.pdf. O site não carrega ferramentas de análise nem CAPTCHA de terceiros e não define cookies para este formulário. Para informações sobre o tratamento e para exercer os seus direitos sobre os dados pessoais, contacte info@sequi.it. Não inclua dados sensíveis nas notas.
